## 📖 درباره این اثر

این کتاب، ترجمه و ویرایش فارسی دوره رسمی **Generative AI for Beginners** از شرکت **مایکروسافت (Microsoft)** است. در ۲۲ درس این دوره، مباحث هوش مصنوعی مولد از مفاهیم اولیه مدل‌های زبانی و مهندسی پرامپت تا معماری RAG و ایجنت‌های هوشمند بررسی می‌شود.

برای دسترسی راحت‌تر، کل سرفصل‌ها به همراه کدهای برنامه‌نویسی، تصاویر و لینک مستقیم ویدیوهای آموزشی در قالب یک فایل PDF استاندارد تدوین شده است تا هم برای مطالعه در سیستم و هم برای چاپ کاغذی بدون به‌هم‌ریختگی قابل استفاده باشد.

## 🗂️ فهرست سرفصل‌های کتاب (۲۲ درس)

| فصل | عنوان درس | مباحث کلیدی |
| :---: | :--- | :--- |
| **۰۰** | مقدمه و سناریوی دوره | معرفی استارتاپ فرضی آموزش و نحوه تعامل با دوره |
| **۰۱** | مقدمه‌ای بر هوش مصنوعی مولد و LLMها | تاریخچه، ترنسفورمرها و نحوه عملکرد مدل‌های زبانی |
| **۰۲** | بررسی و مقایسه مدل‌های زبانی بزرگ | مقایسه مدل‌های متن، تصویر، صدا، مدل‌های اختصاصی و کوچک (SLM) |
| **۰۳** | استفاده مسئولانه و اخلاقی از AI | عدالت، شفافیت، سوگیری الگوریتم‌ها و چارچوب‌های اخلاقی |
| **۰۴** | مبانی مهندسی پرامپت (Prompt Engineering) | ساختار پرامپت، تکنیک‌های One-Shot ،Few-Shot و هدایت مدل |
| **۰۵** | خلق پرامپت‌های پیشرفته | زنجیره تفکر (Chain of Thought)، خودسازگاری و جهت‌دهی دقیق |
| **۰۶** | ساخت برنامه‌های تولید متن | اتصال SDK، مدیریت APIها و اجرای کلاینت‌های متنی |
| **۰۷** | ساخت برنامه‌های چت‌بات تعاملی | مدیریت هیستوری گفتگو، کانتکست پنجره و سیستم پرامپت چت |
| **۰۸** | ساخت برنامه‌های جستجو بر پایه سرچ معنایی | امبدینگ‌ها، فضاهای برداری و مفاهیم سرچ مفهومی |
| **۰۹** | ساخت برنامه‌های تولید تصویر | دستورات تصویری، مدل‌های انتشار (DALL-E) و پارامترها |
| **۱۰** | ساخت برنامه‌های کم‌کد (Low-Code AI) | توسعه سریع ابزارهای هوش مصنوعی با حداقل کدنویسی |
| **۱۱** | یکپارچه‌سازی عملکردها (Function Calling) | اتصال مدل زبانی به توابع بیرونی، APIها و ابزارها |
| **۱۲** | طراحی رابط کاربری برای برنامه‌های هوش مصنوعی | الگوهای UX، استریم پاسخ‌ها، بازخورد و لودینگ هوشمند |
| **۱۳** | امنیت و مراقبت در برنامه‌های AI | مقابله با Prompt Injection، جلوگیری از Jailbreak و فیلترها |
| **۱۴** | چرخه عمر و عملیات مدل‌های زبانی (LLMOps) | استقرار پایدار، پایش، لاگ‌گیری و نگهداری مدل‌ها در پروداکشن |
| **۱۵** | معماری بازیابی افزوده بر پایه اطلاعات (RAG) | پایگاه‌داده‌های برداری، بخش‌بندی متون و پاسخ به اسناد اختصاصی |
| **۱۶** | سیستم‌های متن‌باز و مدل‌های محلی (Open Source) | اجرای مدل‌های HuggingFace، مدل‌های محلی و صرفه‌جویی هزینه |
| **۱۷** | هوش مصنوعی و کدنویسی (AI for Coding) | کار با GitHub Copilot، تحلیل کد و تولید خودکار آزمون‌ها |
| **۱۸** | میزان‌سازی دقیق مدل‌ها (Fine-Tuning) | چه زمانی فاین‌تیون کنیم؟ آماده‌سازی دیتاست و ارزیابی |
| **۱۹** | ارزیابی و سنجش عملکرد برنامه‌های AI | متریک‌های ارزیابی، مقایسه پاسخ‌ها و بنچمارک‌های خروجی |
| **۲۰** | ساخت ایجنت‌های هوشمند خودکار (AI Agents) | ایجنت‌های تصمیم‌گیر، ابزارهای کنش‌گر و حلقه استدلال ReAct |
| **۲۱** | ایجنت‌های چندگانه و تیم‌های خودمختار | همکاری چندین ایجنت، تقسیم وظایف و ساختار Multi-Agent |
